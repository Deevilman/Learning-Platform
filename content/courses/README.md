# Kurser

Hvert kursus er én fil her: `<slug>.md` (se [CONTENT_GUIDE.md](../../CONTENT_GUIDE.md), afsnit 0).

**Tilføj eller ret et kursus via GitHub:** åbn denne mappe på github.com → *Add file → Upload files* → træk kursusfilen ind → *Commit changes*. GitHub tjekker og bygger kurset og opdaterer siden efter et par minutter. Er der fejl i filen, bliver siden ikke opdateret, og du får et issue med fejlene og linjenumrene.

Vil du bare bruge et kursus selv, kan du også tilføje det direkte i appen under *Mere → Tilføj kursus*.
